# DeerFoliaPlus 26.3 升级记录

本次从 `ver/26.2` 的 `f24ea8b92ea076e182cfea3e69b24d42d138ea1d` 创建 `ver/26.3.x` 分支，升级到 Minecraft 26.3。

## 上游与构建

- DeerFolia：`10d9b984691b56c2841988292fa2510c690ab311`，对应版本 `26.3.0-10d9b98`，包含已完成的第一批 Lithium 优化及安全异步寻路修复。
- 项目版本：`26.3-R0.1-SNAPSHOT`；`mcVersion`、`apiVersion`：`26.3`。
- Java 25；Gradle Wrapper 9.8.1；paperweight 2.0.0-beta.24，与上游一致。
- 更新服务器构建补丁的 Leafpile 依赖上下文，以适配上游 BOM 与拆分后的模块。
- 保留原有全部 13 个 `.patch` 文件路径，没有新增或重命名补丁。`0008-Update-fake-player-internals-for-26.2.patch` 保留历史文件名，其内容已在 26.3 上重新应用和验证。

## 兼容处理

| 位置 | 26.3 适配 |
| --- | --- |
| `AbstractContainerMenu` | 保留新版点击按钮/动作辅助方法，同时保留假人菜单占位物品检查。 |
| `ChunkGeneratorStructureState` | 强要塞布局转换与上游结构种子分支合并；保留 `abandoned_camp` 等完整 Spigot seed 映射及命名空间检查。 |
| `PlayerChunkSender` | 保留 DeerFolia 的区块发包辅助方法和 Anti-Xray 处理，在正常开始监听区块时调用 Servux 钩子。 |
| `ServerGamePacketListenerImpl` | 将躺下姿态的坐标锁定接入新版共同位置处理方法，覆盖普通移动和传送确认；保留纯转头数据包的语义。 |
| `CraftWorld` | 保留 26.3 粒子 API 的三轴速度与随机化参数，同时在默认接收者列表中跳过假人。 |

独立源码还适配了 26.3 的永久无敌、受击同步、挥手动画和世界时钟 API。`/god` 在目标实体所属区域线程中读取并切换永久无敌状态，避免把临时无敌状态当成已开启的 God 模式；时间命令保留 `TimeSkipEvent` 的取消和时间修改行为。假人补丁恢复了上游 `PlayerList` 仍在使用的 `Maps` 导入。
