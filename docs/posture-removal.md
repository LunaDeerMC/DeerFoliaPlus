# 移除 Posture System

本次在 `ver/26.3.x` 中完整移除 DeerFoliaPlus 自带的姿态功能：

- 删除 `/sit`、`/lay`、`/crawl`、`/get-up` 及相关权限。
- 删除空手右键楼梯/台阶坐下、椅子检测、座椅实体和姿态会话实现。
- 删除姿态配置类、监听器注册和姿态专用 NMS 补丁，恢复上游的输入、移动、传送确认与玩家姿态处理。
- 更新 README 和运行回归工具。其他功能的补丁路径保留，补丁总数从 13 个变为 12 个。

旧 `deer-folia-plus.yml` 的 `posture` 段会保留但失效，不会恢复命令或监听器；新生成的默认配置不再包含该段。原有座椅实体不持久化，因此正常停服后升级不需要额外的世界数据迁移。Minecraft 原生的潜行、游泳及低矮空间通行行为继续由上游实现处理。

初次升级版本 `26.3.0-8b479ea` 及其验证记录仍保留原始内容，本次删除在后续提交中生效。
